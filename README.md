# 领航体系 · 阿郎的教学网站（内部教学门户）

一个用于内部教学的链上工具门户。学员注册后由管理员审批开通权限，才能使用只读查询与链上执行教学工具。

## 为什么开源

教学场景下，学员需要先确认工具不会窃取资产才敢用。本仓库公开全部服务端与前端代码，任何人都可以自行检查：

- 不收集、不上传私钥、助记词或钱包密码
- 所有链上写操作都由学员本人在自己的钱包里确认
- 账号、密码、审计日志不包含在本仓库中

## 目录结构

| 文件 | 说明 |
|---|---|
| server.js | 门户服务端（Node.js，无第三方依赖） |
| mobile/ailgns-tool-mobile.html | AiLGNS 教学工具页（资产查询 + 提取操作） |
| start-portal.bat | Windows 下双击启动 |
| logo-1234-transparent.png | 站点图标 |

## 运行方式

需要 Node.js 18 或以上版本。

```
node server.js
```

默认监听 http://localhost:8123 。首次启动会自动创建管理员账号，并把初始密码写入 data/初始管理员密码.txt，请及时登录后台修改密码。

## 权限模型

- 只读查询：查看链上公开数据
- 教学：包含执行类操作，需要管理员逐人审批开通
- 有效期：管理员可设置 1 个月、1 年或终身有效

## 安全说明

- 门户不接触私钥、助记词或钱包密码
- 执行类操作在学员自己的浏览器中由钱包签名，服务端只负责分发页面
- 本仓库不包含任何真实账号、密码或审计日志

## 不包含的内容

data/ 目录（账号、密码、审计日志）不在本仓库中。克隆后首次运行会自动重新生成。
